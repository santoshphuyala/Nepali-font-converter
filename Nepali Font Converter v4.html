Kantipur, Fantasy Himali, Sagarmatha and Kanchan are handled with the Preeti key layout; if a glyph differs in your font, fix the word once and it is remembered. Legacy text displays correctly only if that font is installed. Excel: only the font name of converted cells changes (size, colour, borders, formats, formulas and sheet names stay). PowerPoint: slides, notes, tables, charts and SmartArt text are converted run by run. Text inside pictures, and data inside embedded chart workbooks, cannot be converted. Text files keep every line break and tab. English words: in Word files, runs set in a non-Nepali font (e.g. Times New Roman) are skipped automatically; in pasted text, common English words, acronyms, emails and links are kept, and the EN button next to any word keeps or releases it.
