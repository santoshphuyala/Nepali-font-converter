Saved fixes & rules

Three ways to fix a wrong conversion, all remembered on this device: (1) edit a word in the list above; (2) edit the Output yourself, then press Save my edits; (3) add a rule for text that always converts wrong.

Kantipur, Fantasy Himali, Sagarmatha and Kanchan are handled with the Preeti key layout; if a glyph differs in your font, fix the word once and it is remembered. Legacy text displays correctly only if that font is installed. English words: in Word files, runs set in a non-Nepali font (e.g. Times New Roman) are skipped automatically; in pasted text, common English words, acronyms, emails and links are kept, and the EN button next to any word keeps or releases it.
